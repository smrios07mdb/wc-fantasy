DESIGN SYSTEM · v1

The system behind a legible live-scores product.

A dark-first, data-dense design language for a private World Cup fantasy league. Built so the three things that matter most — the score, the lock status, and whose turn it is — are never obscured. Sleeper-grade craft; when a flourish and a fact compete, the fact wins.

Why dark-first

Justified, not defaulted. Managers live on this app during evening match windows — a dark canvas reduces glare across a ~month of late kickoffs, suits OLED phones in a dark room, and makes the functional colors (live red, frozen steel, yet-to-play amber) read as signals against a calm neutral rather than competing with a bright field. Light theme is a first-class toggle for daytime and accessibility, shipped here in parallel.

12

Tailwind handoff

Every token maps 1:1 to a tailwind.config theme extension. CSS variables stay the runtime source (theme + accent swap at the <html> level); Tailwind classes reference them so Code writes bg-surface-1 text-live, not raw hex.
