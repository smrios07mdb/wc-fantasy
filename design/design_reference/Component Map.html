05 — Flag, don't invent

Open gaps

The four "brain" docs (PROJECT / ARCHITECTURE / DECISIONS / SCORING.md) were never provided. These remain genuinely undecided and are surfaced in-UI as provisional / illustrative — resolve via a decision thread, not in code.

  1. SCORING.md — categories & point values.The box-score layout is final; the values are illustrative and flagged in-UI. Don't freeze values into shared scoring logic.
  2. Final playoff field size (8 vs 10) + exact per-round cut counts.Modeled as commissioner-set (fieldPlan / cutSchedule), provisional until the group→playoff transition. The Commissioner screen locks it; the spec value is TBD.
  3. Group-stage period count feeding seeding, and weekly-record tie handling beyond total points.The all-play-all record assumes ties break on total points; deeper tie rules undefined.
✓

Resolved — don't reopen

FAAB tie on equal bids → breaks on the rolling waiver order (stated in Waivers UI). Gold removed project-wide — --pos-gk slate, --ytp orange. League name stays the "WC Fantasy League" placeholder; no locale flavoring.
