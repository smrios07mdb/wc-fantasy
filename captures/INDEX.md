## Reading notes for Claude Design

- **fullPage scroll artifact**: fullPage shots paint the fixed bottom nav at its mid-image scroll offset. This is a known Playwright `fullPage` capture artifact, not a layout bug — don't read it as the nav floating mid-page.
- **`/vsfield?manager=` is viewport-dependent**: mobile widths auto-open the KOSheet jersey-XI drill-in from the `manager` param; desktop shows the cockpit compare view instead. Same URL, two different UIs by design.
- **Phase coverage is uneven by surface**: knockout is captured on every surface. Group phase is carried only by `/vsfield?period=MD1` and `/games/<MD1 id>`. `/lineup` group-phase is NOT captured — its `PeriodTabs` are client-`onClick`, which the read-only no-click fence for this pass barred.
- **KOCeremony suppression**: the KOCeremony takeover was suppressed on the seeded `/vsfield` shots via a client-local `localStorage` shim (zero server writes). The ceremony itself is still captured first-class on the one unseeded `/vsfield` surface — at 390/1440 only, no 360.
- **Deferred states** (per the no-click fence, not yet captured): NationFilter-expanded, `BidComposer`/`?bid=` (claims closed), tab toggles, and all other write-dependent states.
