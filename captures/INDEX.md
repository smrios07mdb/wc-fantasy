## Reading notes for Claude Design

- **fullPage scroll artifact**: fullPage shots paint the fixed bottom nav at its mid-image scroll offset. This is a known Playwright `fullPage` capture artifact, not a layout bug — don't read it as the nav floating mid-page.
- **`/vsfield?manager=` is viewport-dependent**: mobile widths auto-open the KOSheet jersey-XI drill-in from the `manager` param; desktop shows the cockpit compare view instead. Same URL, two different UIs by design.
- **Phase coverage is uneven by surface**: knockout is captured on every surface. Group phase is carried only by `/vsfield?period=MD1` and `/games/<MD1 id>`. `/lineup` group-phase is NOT captured — its `PeriodTabs` are client-`onClick`, which the read-only no-click fence for this pass barred.
- **KOCeremony suppression**: the KOCeremony takeover was suppressed on the seeded `/vsfield` shots via a client-local `localStorage` shim (zero server writes). The ceremony itself is still captured first-class on the one unseeded `/vsfield` surface — at 390/1440 only, no 360.
- **Deferred states** (per the no-click fence, not yet captured): NationFilter-expanded, `BidComposer`/`?bid=` (claims closed), tab toggles, and all other write-dependent states.

Wave 1.5 additions (same fence — goto + screenshot only):

- **Signed-out set is a no-state context**: `public-landing` / `public-signin` / `public-denied` were captured with NO injected session (`--no-auth`) — a fresh browser context, zero server writes. Authed `/` renders the Dashboard hub (`dashboard__hub-live__*`); signed-out `/` renders the marketing landing. Same route, two first-class states.
- **`/sign-in` is the REQUEST view only**: the "check your email" confirmation is post-submit (a form fill) → deferred with the other click/write-gated states.
- **Dashboard is the CURRENT live phase** (knockouts, R16): pre-draft/draft/group dashboard phases derive from server state (`draft.status` / period kind), not a read-only param → not capturable in this pass.
- **Wave-1.5 deferrals (client-`onClick`, no `searchParams` read)**: `/standings` Cumulative tab (Matchday default captured), `/playoffs` board↔ladder toggle (Theater default captured). `/commish` non-default tabs ARE `?tab=`-reachable (`app/commish/page.tsx` honors an explicit `?tab`), but Wave 1.5 scope captured the default (Playoff cuts) only — the other tabs defer by scope, not by fence.
- **`/playoffs` was captured ceremony-suppressed** (same client-local `localStorage` shim as `/vsfield` — fresh contexts look like new devices).

fence — every capture context aborts ALL non-GET requests at the Playwright driver layer, so no
write can leave the browser. Interactions are pure client state (open sheet/panel/tab,
client-side filter, selection), classified against component source before scripting; mutating
controls (save/submit/claim/pick/star/sign-out/commish writes) were never activated.
